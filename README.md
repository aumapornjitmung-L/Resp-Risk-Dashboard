# แดชบอร์ดพยากรณ์ความเสี่ยงโรคระบบทางเดินหายใจ (Streamlit)

แดชบอร์ดประกอบวิทยานิพนธ์ **“การพยากรณ์ความเสี่ยงการเกิดโรคระบบทางเดินหายใจตามปัจจัยด้านสิ่งแวดล้อม
โดยใช้การเรียนรู้ของเครื่อง”** ใช้ข้อมูล 77 จังหวัด × 36 เดือน (พ.ศ. 2566–2568) และ 4 แบบจำลอง
(Logistic Regression, SVM, Random Forest, XGBoost) ผลบนหน้าจอคำนวณด้วยตรรกะเดียวกับโน้ตบุ๊ก
`NewRiskLevel_EN` จึงตรงกับตัวเลขในสไลด์

## เริ่มใช้งาน

```bash
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt     # ต้องใช้ Python 3.13
streamlit run app.py
```

เปิดเบราว์เซอร์ที่ `http://localhost:8501`

หรือใช้ Docker

```bash
docker build -t resp-dashboard .
docker run -p 8501:8501 resp-dashboard
```

## วิธีนำเข้าข้อมูล (เมนู “นำเข้าข้อมูล” ที่หน้าแดชบอร์ดหลัก)

| โหมด | ไฟล์ที่ต้องเลือก | เวลาโดยประมาณ |
|---|---|---|
| **ไฟล์ดิบ 3 ไฟล์** | ผู้ป่วยนอก (RS data), PM2.5 รายวัน, สภาพอากาศรายวัน — รองรับ `.csv` และ `.xlsx` | 1–2 นาที (Excel ใหญ่ใช้เวลาอ่านนาน) |
| **CSV รายเดือน** | ตารางจังหวัด-เดือนที่ประมวลผลแล้ว (ดาวน์โหลดจากแดชบอร์ดนี้ได้) | ไม่กี่วินาที |

คอลัมน์ที่ต้องมี

- **ผู้ป่วย:** `Date_serv, Birth day, pid, sex, Province name`
- **PM2.5:** `Date, Province ID, PM2.5, Province Name`
- **สภาพอากาศ:** Excel หลายชีต (ชีตสถานีมี `ID, Province`; ชีตข้อมูลมี `ID, Date, Wind Speed, Temp., Humi., Pres., Prec.`)
  หรือ CSV ข้อมูลอากาศ + ไฟล์สถานี `ID, Province` แยกอีกไฟล์
- **CSV รายเดือน:** ดูรายการคอลัมน์และดาวน์โหลดเทมเพลตได้ในแอป

หลังประมวลผลแล้ว ระบบแสดงตาราง “ตรวจเทียบกับค่าบนสไลด์” (ใช้กับชุดข้อมูลเดิมของวิทยานิพนธ์)

## หน้าต่างๆ

1. **แดชบอร์ดหลัก** — นำเข้าข้อมูล, ตัวเลขสรุป, ระดับความเสี่ยง, เปรียบเทียบโมเดล, แนวโน้มรายเดือน, ตรวจเทียบสไลด์
2. **ผลเปรียบเทียบแบบจำลอง** — ตารางประสิทธิภาพ, ผลรายคลาส, Confusion Matrix, ROC, วัดเวลาประมวลผล
3. **ตัวแปรสำคัญ** — ความสำคัญของตัวแปร (RF), เทียบ 19 → 12 ตัวแปร
4. **สำรวจข้อมูลและความสัมพันธ์** — ฤดูกาล/ภูมิภาค, Pearson, ANOVA, เจาะเดือน
5. **คุณภาพข้อมูล** — ขั้นตอนเตรียมข้อมูล, จังหวัดที่ไม่มีสถานี, VIF
6. **ทำนายระดับความเสี่ยง** — กรอกค่าเอง หรือนำเข้า CSV หลายแถว

## ข้อมูลและความเป็นส่วนตัว

- **ห้ามใส่ไฟล์ข้อมูลวิจัยลงใน Git** — `.gitignore` กันไฟล์ `.csv/.xlsx/.pkl` ไว้แล้ว
- ข้อมูลที่ผู้ใช้นำเข้าอยู่ในหน่วยความจำของเซสชันเท่านั้น ไม่ถูกบันทึกลงดิสก์ของเซิร์ฟเวอร์
- `data/thesis_reference.json` เก็บเฉพาะ **ตัวเลขสรุปที่ปรากฏในสไลด์** (ไม่มีข้อมูลรายระเบียน)
  ใช้แสดงค่าอ้างอิงก่อนนำเข้าข้อมูล ลบไฟล์นี้ได้ แอปจะทำงานต่อโดยไม่แสดงส่วนอ้างอิง

## ทดสอบและ CI

```bash
pip install -r requirements-dev.txt
pytest -q
```

`.gitlab-ci.yml` มี 3 ขั้น: `lint` → `test` → `build_image` (สร้าง Docker image ขึ้น Container Registry
เมื่ออยู่บน default branch) ทดสอบใช้ข้อมูลสังเคราะห์ จึงไม่ต้องมีไฟล์ข้อมูลจริงบน CI

## หมายเหตุด้านการตีความ

- Risk Level สร้างจาก **จำนวนผู้ป่วยรายเดือน** (>150 Extremely, >100 High, ≥50 Moderate, นอกนั้น Low) โดยยืมค่าตัด
  50/100/150 จากเกณฑ์ผลกระทบของกรมควบคุมโรค (ซึ่งเดิมใช้อัตราป่วยต่อแสนประชากร) ระดับความเสี่ยงจึงสะท้อนขนาดประชากร
  และการเข้าถึงบริการด้วย
- ผลเป็นเครื่องมือคัดกรองเบื้องต้น ไม่ใช่การระบุสาเหตุของโรค
- แบ่งชุดฝึก/ทดสอบครั้งเดียว (stratified 80/20, `random_state = 42`) ไม่มี Cross-Validation และไม่ปรับจูน
  ตัวเลขอาจสูงกว่าการใช้งานจริง
- **ผลขึ้นกับเวอร์ชันไลบรารี:** ชุดทดสอบมีคลาส High เพียง 6 และ Moderate 15 ตัวอย่าง ทำให้ผลของ Random Forest และ
  XGBoost เปลี่ยนได้เมื่อเปลี่ยนเวอร์ชัน scikit-learn/xgboost (ทดสอบแล้ว: ชุดเวอร์ชันเก่าให้ RF Accuracy 0.948 แทน 0.959)
  `requirements.txt` จึงล็อกเวอร์ชันที่ให้ตัวเลขตรงกับสไลด์ ใช้ Python 3.13 ตามไฟล์ Docker/CI
